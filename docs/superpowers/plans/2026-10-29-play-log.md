# Play Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An opt-in play log that records every attempt and shot, shares as a JSON file through the
share sheet, and a report tool that summarises such files.

**Architecture:** A pure module `src/plays.js` builds and trims the log (tested); `src/ui.js` calls
it at the existing hook points and stores it under `splice-plays`. The Run tab gets a Play log block.
`tools/plays.mjs` reads shared files and prints a report.

**Tech Stack:** Vanilla ES modules, `node --test`, `localStorage`, Web Share API.

**Spec:** `docs/superpowers/specs/2026-10-29-play-log-design.md`

## Global Constraints

- Every `localStorage` key starts with `splice-`: `splice-plays` (log, holds the switch and the
  install id too).
- No visible text in code: all copy in `lang/en.json`. Sentence case, no em-dashes, typographic
  apostrophes (’).
- No `Math.random` in `src/`. The install id uses `crypto.getRandomValues`.
- Tracking off: nothing recorded, nothing stored, no per-shot work.
- The log never breaks play: every log read and write is in `try`/`catch`; a failed write is
  ignored.
- No network calls. Sharing only on a tap.
- `node --test` (not `node --test tests/`). Commits: Conventional Commits, no attribution lines.
- Match the surrounding code: terse, short names, one-line comments.

## Review Focus

- Storage full (`setItem` throws): the shot and the game save still go through. Test in Task 1
  (`trim` keeps the log under the cap) and a guarded write in Task 2.
- Corrupt or foreign `splice-plays` (bad JSON, wrong shape): `logFrom` returns a fresh, valid log,
  keeping the `on` switch only if it is a boolean. Test in Task 1.
- Reload mid level: the open attempt continues when level and fails match, else closes as `left`.
  Test in Task 1 (`resume`).
- Tracking switched off with an open attempt: the open attempt is dropped, closed ones kept. Test in
  Task 1 (`setOn`).
- Share cancelled (`AbortError`): no clear question, the log is unchanged. Manual check in Task 3.

### Task 1: Pure log module, need and build stamp

**Files:**
- Create: `src/plays.js`, `src/build.js`, `tests/plays.test.mjs`
- Modify: `src/core.js` (`startState`, `toSave`, `fromSave`, `validSave`), `sw.js` (`SHELL`, `CACHE`
  to `splice-6`), `.github/workflows/pages.yml` (stamp step)

**Interfaces:**
- Produces, all in `src/plays.js`, all pure (return a new log or mutate only the log passed in;
  pick one style and keep it, mutating is fine):
  - `PLAYS_V = 1`, `PLAYS_MAX = 1e6` (characters of JSON).
  - `logFrom(o) -> {v, on, id, attempts}`: repairs anything; `id` kept if a string of 8 to 32
    characters, else `null` (the UI fills it).
  - `attemptOf(S, {ice, deck, at}) -> attempt`: `{level, fails, kind, cols, colours, hardness, ice,
    items: itemPlan(level).has, itemBubbles, limit: S.maxShots, need: S.need ?? null, deck: {...deck.items},
    frags: deck.frags, at, t: 0, shots: [], end: null, left: null, paid: null}`. `colours` is the
    number of distinct colours on the board, `itemBubbles` the grid values `>= ITEM_BASE`.
  - `open(log) -> attempt | null`: the last attempt when its `end` is null.
  - `begin(log, attempt)`: closes an open attempt as `left`, then appends `attempt`.
  - `resume(log, S) -> boolean`: true when the open attempt has `S.level` and `S.fails`; otherwise
    closes it as `left` and returns false.
  - `close(log, end, S, paid?)`: `end` is `'won'`, `'lost-shots'`, `'lost-line'` or `'left'`; sets
    `left = S.shots` (or null without `S`) and `paid`.
  - `shot(log, entry)` and `use(log, id)`: append to the open attempt's `shots`; no-op without one.
    A use is `{u: id, n}`, `n` the number of the shot it came before (shot entries so far + 1, so
    Overclock's extra shots do not skew it).
  - `setOn(log, on)`: turning off drops an open attempt.
  - `trim(log, max = PLAYS_MAX)`: drops the oldest attempts until `JSON.stringify(log).length <= max`;
    never drops the open one.
  - `fileOf(log, device, build, date) -> {name, text}`: `name` is `splice-plays-YYYY-MM-DD.json`
    from `date`; `text` is JSON of `{v, build, id, device, attempts}`.
- Shot entry (built in Task 2, defined here so tests and the report agree): `{n, s, c, sw, st, x, am,
  a, l, p, d, f, b, pc}`: shot number, shots left before, colour (0..5) or item id, swaps
  `[[src, ms], ...]` (`src` `'tap'`, `'wheel'` or `'lock'`; `ms` from that swap to the release),
  aim started in the strip (0/1), cancelled aims since the last shot, aim ms, angle (3 decimals),
  landing `[r, c]` or null, popped count, dropped count, item bubbles set off, bubbles left, `pct()`.
- `src/build.js`: `export const BUILD = 'dev';`
- `S.need`: the raw bot need, set by `startState`, in `toSave`, `fromSave` default `null`,
  `validSave` accepts it missing, `null` or a positive number.

- [ ] **Step 1: Write the failing tests** in `tests/plays.test.mjs`:
  - `logFrom` on `null`, `'x'`, `{attempts: 5}`, `{on: 'yes'}` gives `v === 1`, `on === false`,
    `attempts` `[]`; on a valid log returns its attempts unchanged.
  - `attemptOf(startState(12, 0), {ice: null, deck: {frags: 3, items: {bomb: 1}}, at: 'T'})` has
    `level 12`, `limit === S.maxShots`, `need === S.need`, `end === null`, `deck.bomb === 1`.
  - `begin` twice: the first attempt ends `'left'`; `open(log)` is the second.
  - `resume`: same level and fails keeps it open (`true`); other fails closes it `'left'` (`false`).
  - `close(log, 'won', S, {frags: 9})` sets `left === S.shots`, `paid.frags === 9`, `open(log) === null`.
  - `shot` and `use` without an open attempt change nothing.
  - `setOn(log, false)` with one closed and one open attempt leaves one attempt, closed.
  - `trim` on a log of 200 attempts of 50 shots with `max = 20000` gives length `<= 20000`, keeps
    the newest and the open one.
  - `fileOf(log, {w: 390}, 'abc1234', new Date('2026-10-29T10:00:00Z')).name ===
    'splice-plays-2026-10-29.json'`; parsed text has `build 'abc1234'` and `device.w 390`.
  - `startState(5, 0).need` is a positive number, and `fromSave(toSave(S)).need === S.need`;
    `validSave` of a save with `need` removed is true.

### Task 2: Recording in the UI

**Files:**
- Modify: `src/ui.js`

**Interfaces:**
- Consumes: Task 1's `src/plays.js` API, `BUILD`.
- Produces for Task 3: `plays` (the log in memory), `savePlays()`, `PLAYS_KEY = 'splice-plays'`.

- [ ] **Step 1: Load and save.** At start, `plays = logFrom(JSON.parse(localStorage[PLAYS_KEY]))`
  in `try`; fill a missing `id` with 16 hex characters from `crypto.getRandomValues`. `savePlays()`
  runs `trim` then `setItem` in `try`, and does nothing while `!plays.on`.
- [ ] **Step 2: Attempts.** With `plays.on`:
  - `start(s)` from `begin()`: `begin(plays, attemptOf(S, {ice, deck, at: new Date().toISOString()}))`.
  - `start(s)` from `load()` (a saved board): `resume(plays, S)`; when false, no new attempt (the
    next `begin()` starts one).
  - On a win in `shoot()`: `close(plays, 'won', S, paid)`. On a loss in `land()`: `'lost-shots'`
    when `S.shots <= 0`, else `'lost-line'`. Start over and Reset progress go through `begin()`, so
    the open attempt closes `left` there.
  - Active time: keep `tAt` (ms) while the page is visible; add `now - tAt` to the open attempt's
    `t` on every shot, on `visibilitychange` to hidden, and at close. Store `t` in seconds, 1 decimal.
- [ ] **Step 3: Shots.** Keep per-shot counters reset after each shot: `swaps` (`trySwap` pushes
  `['tap' | 'wheel', performance.now()]`; a swap the lock ignores pushes `'lock'`), `cancels` (an aim
  that moved below the line, counted once per press), `strip` (`tapAt` was set at press), `pressAt`.
  In `shoot()` after a successful `fire`, build the shot entry from Task 1's key list (swap `ms` is
  release time minus swap time) and call `shot(plays, entry)`, then `savePlays()`.
- [ ] **Step 4: Item uses.** Each instant use (Overclock in the drawer and on the sheet, Decrypt,
  ICE breaker, Rollback) calls `use(plays, id)` and `savePlays()`.
- [ ] **Step 5: Verify by hand.** Serve on 8080, `localStorage['splice-plays'] = '{"on":true}'`,
  reload, play 3 shots, swap twice, reload, play 2 more. Expected: one open attempt with 5 shots, the
  swaps on shot 4's entry, `t` > 0. Then `{"on":false}`: playing writes nothing new.
- [ ] **Step 6: Run** `node --test`. Expected: all pass.
- [ ] **Step 7: Commit** `feat: record attempts and shots in the play log`.

### Task 3: Play log block in the menu

**Files:**
- Modify: `index.html` (Run tab, above `#mReset`), `style.css`, `src/ui.js` (`menuText`, `ask`,
  `#sheetB`, `resetAll`), `lang/en.json`

**Interfaces:**
- Consumes: Task 2's `plays`, `savePlays()`, `PLAYS_KEY`; Task 1's `setOn`, `fileOf`; `BUILD`.

- [ ] **Step 1: Markup and copy.** A block with a heading, a switch (`#pOn`, a checkbox styled like
  the menu buttons), a count line (`#pCount`), `#pShare` and `#pClear`. Keys in `lang/en.json`:
  `playLog` "Play log", `playTrack` "Track plays", `playCount` "{n} levels logged", `playShare`
  "Share log", `playClear` "Clear log", `playClearAsk` "Clear the play log?", `playClearText`
  "The levels logged so far are deleted.", `playClearYes` "Clear", `playKeep` "Keep",
  `playOffText` "Off. Nothing is recorded.". Share and Clear are disabled with no attempts; the
  count line shows `playOffText` while off.
- [ ] **Step 2: Switch.** `#pOn` change: `setOn(plays, on)`, then write the log (when turning off,
  write it directly, since `savePlays` skips while off), redraw the menu text.
- [ ] **Step 3: Share.** `#pShare` click, all synchronous up to the share call: device
  `{w: innerWidth, h: innerHeight, dpr: devicePixelRatio, touch: matchMedia('(pointer: coarse)').matches,
  reduced, lang}`, `fileOf(plays, device, BUILD, new Date())`, a `File` of type `application/json`.
  If `navigator.canShare?.({files: [f]})`, `await navigator.share({files: [f], title: name})`;
  on resolve `ask('clearLog')`; on `AbortError` nothing; on another error fall through to the
  download. Download: a blob URL on a temporary `<a download>`, click, revoke, then `ask('clearLog')`.
- [ ] **Step 4: Questions.** Extend `ask` with `'clear'` (from `#pClear`) and `'clearLog'` (after a
  share): title `playClearAsk`, text `playClearText`, confirm `playClearYes`, cancel `playKeep` (for
  `'clearLog'`) or `cancel`. `#sheetB` for both: `plays.attempts = []` (an open attempt included;
  the next `begin()` starts fresh), write, close the sheet, redraw the menu text.
- [ ] **Step 5: Reset progress** also empties `plays.attempts` and writes the log; it keeps `on` and
  `id`.
- [ ] **Step 6: Verify by hand.** Desktop Chrome on 8080 (download path): switch on, play a level,
  Share log downloads `splice-plays-2026-10-29.json` and asks to clear; Keep leaves the count.
  Phone (share path) is checked by the owner. Cancelling the share sheet asks nothing.
- [ ] **Step 7: Run** `node --test` (the lang test checks the new keys). Expected: all pass.
- [ ] **Step 8: Commit** `feat: add the play log to the Run tab`.

- [ ] **Step 3: Implement** `report` with these sections, plain text like `tools/sim.mjs`:
