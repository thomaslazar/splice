# Splice

An ad-free, cyberpunk bubble shooter for phones. Fire packets into the hanging ICE;
three or more of one colour pop, and everything cut off from the ceiling falls.
Levels are generated endlessly, and you only get colours that are still on the board.

Run it with `python3 -m http.server` in the repo root and open http://localhost:8000/; run the tests with `node --test`.

Work in progress. Developer notes are in `CLAUDE.md`.
