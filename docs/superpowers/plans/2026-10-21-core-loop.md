# Splice Core Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable, endless, seeded bubble shooter core loop for phones: tall scrolling levels (designed and noise), aiming with a full bounce path, popping, dropping, fair colour dealing, a calculated shot limit, win, loss, retry and restart.

**Architecture:** Pure rules in `src/core.js` (geometry, physics, matching, dealing, state, saves) and `src/levels.js` (difficulty, layout generation, colouring, shot limit), both free of DOM and storage and unit tested with `node --test`. `src/ui.js` draws on a canvas, handles input and scrolling, and saves to `localStorage`. `tools/sim.mjs` plays the same core with a greedy bot to calibrate the shot limit.

**Tech Stack:** Vanilla HTML, CSS, ES modules, canvas 2D. Node's built-in `node:test` and `node:assert/strict`. No dependencies, no build step, no `package.json`.

**Spec:** `docs/superpowers/specs/2026-10-21-core-loop-design.md`. Read it before any task. Project notes: `CLAUDE.md`.

**Prototype:** `/Users/ibn/Development/Splice/spike/index.html` (absolute path; it is gitignored, so it is not in a worktree). It is a throwaway single file. Port its algorithms where this plan points to it, but restructure into the modules below, remove all `Math.random`, and work in radius units instead of pixels.

## Global Constraints

- No frameworks, no dependencies, no build step. ES modules served statically (`python3 -m http.server`); `file://` does not work.
- Run tests with `node --test` from the repo root (not `node --test tests/`).
- `src/core.js` and `src/levels.js`: no DOM, no storage, no `Math.random`. Everything random comes from `mulberry32(hash(...))`.
- A level is fully reproducible from `(level, fails)`.
- All visible text lives in `lang/en.json`, read with `t('key', {placeholders})`. Sentence case, short and plain. No em-dashes. Typographic apostrophes (’) in visible text.
- Dark only. No light mode.
- Match the surrounding style: compact, terse JS, as in `../kiln/src/core.js`.
- Commits: Conventional Commits, `type: subject`, imperative, lowercase, no period, about 72 chars max. Never add `Co-Authored-By:` or "Generated with" lines.
- Deferred, do not build: PWA files, GitHub Pages workflow, the self-hosted font (use `ui-monospace, Menlo, monospace` for now), translations beyond English, sound.

## Units and coordinates (used by every task)

- Bubble radius is `1`. Row height `RH = Math.sqrt(3)`.
- Cell `(r, c)`: row `r` counts down from the level's ceiling (row 0). Even rows have `cols` cells, odd rows `cols - 1`, shifted right by one radius.
- Centre: `x = 1 + 2c + (r % 2)`, `y = 1 + r * RH`. Board width is `2 * cols`.
- Cell key: `r * 16 + c` (cols never exceed 12).
- Colours are integers `0..5` (hue and symbol index).

## Review Focus

1. A shot that hits a dense area must always land in a free cell; it must never be lost or crash (test in Task 3: straight shot into a full noise board).
2. The last bubble cleared by a shot that also uses the last shot is a win, not a loss (test in Task 4).
3. When a pop removes the colour of the current or next packet, the queue is redrawn from remaining colours; when the board is empty, no deal crashes on an empty colour list (test in Task 4).
4. A broken or foreign `localStorage` save starts the current level fresh instead of crashing (test in Task 4 on `validSave`).
5. A touch that starts in the swap strip never aims or fires, even if the finger drifts out of it (manual check in Task 5).

### Task 2: Level generation and colouring

**Files:**
- Create: `src/levels.js`, `tests/levels.test.mjs`

**Interfaces:**
- Consumes: `mulberry32`, `hash`, `cellsIn`, `key`, `nbrs`, `connected` from `src/core.js`.
- Produces (exported from `src/levels.js`):
  - `difficulty(level) => number` = `Math.min(1, level / 40)`.
  - `isLong(level) => boolean` = `level % 5 === 0`.
  - `makeLayout(level) => {cols, kind: 'designed'|'noise', screens, nColours, cells: Map<key, grp>}`. Cached per level (a `Map`), independent of `fails`.
  - `winRows(cols) => number` = `Math.round(1.7 * cols)` (visible window height in rows).
  - `colourize(layout, level, fails) => Map<key, colour>`.

Generation rules (spec, "Levels"; port the prototype's `shapeMakers`, `generate`, `addStems`, `colourize`, lines 74 to 205):

- One `rnd = mulberry32(hash(level, 7))` drives the whole layout, in this order: kind, cols, screens, then sections.
- Kind: levels 1 and 2 `designed`; from level 3, `noise` with probability 0.25.
- Cols from `{8, 10, 12}` with weights interpolated by `d`: at `d = 0` `[0.4, 0.45, 0.15]`, at `d = 1` `[0.15, 0.45, 0.4]`; on long levels move 0.15 from the 8 weight to the 12 weight (floor 0).
- `nColours = Math.min(6, 3 + Math.floor(d * 3.5))`.
- Section height `sec = Math.round(1.6 * cols)`.
- Designed: `screens = 4 + Math.round(d * 4) + (isLong(level) ? 2 + floor(rnd() * 3) : 0)`; one section per screen at rows `[s * sec, (s + 1) * sec)`. Per section: 2 to `2 + floor(2 + 2d) - 1` shapes, later shapes win, mirrored with p = 0.65, pushed down 2 to 4 rows with p = 0.5; reject and retry (up to 20 tries) when it has fewer than `25 + 30d` cells; group ids `s * 1000 + shape * 100 + band`. After each section, add stems; stems are mirrored in mirrored sections; stem groups get ids from `1e6` up.
- Noise: `screens = 2`, rows `2 * sec + Math.round(d * 6)`, every cell filled, every cell its own group.
- Shape coordinates scale with `cols` (the prototype's shapes use `X = COLS - 1`; keep that).
- Colouring: `rnd = mulberry32(hash(level, fails, 99))`; pick `nColours` of the 6 colours by a seeded shuffle; touching groups differ where possible; noise copies an already coloured neighbour with p = 0.45.

import test from 'node:test';
import assert from 'node:assert/strict';
import { makeLayout, colourize, difficulty, winRows } from '../src/levels.js';
import { connected, rc } from '../src/core.js';

const levels = Array.from({ length: 60 }, (_, i) => i + 1);

test('layouts are deterministic and hang from the ceiling', () => {
  for (const lv of levels) {
    const L = makeLayout(lv);
    assert.deepEqual([...makeLayout(lv).cells], [...L.cells]);
    assert.equal(connected(L.cells, L.cols).size, L.cells.size, `level ${lv} has loose bubbles`);
  }
});
test('kinds, columns, screens and colours follow the rules', () => {
  assert.equal(makeLayout(1).kind, 'designed'); assert.equal(makeLayout(2).kind, 'designed');
  const kinds = { designed: 0, noise: 0 }, cols = { 8: 0, 10: 0, 12: 0 };
  for (let lv = 3; lv <= 400; lv++) { const L = makeLayout(lv); kinds[L.kind]++; cols[L.cols]++;
    if (L.kind === 'noise') assert.equal(L.screens, 2);
    else { const base = 4 + Math.round(difficulty(lv) * 4); assert.ok(L.screens >= base && L.screens <= base + 4); }
    assert.ok(L.nColours >= 3 && L.nColours <= 6); }
  assert.ok(kinds.noise > 60 && kinds.noise < 140, `noise share off: ${kinds.noise}`);
  for (const c in cols) assert.ok(cols[c] > 30, `${c} columns too rare`);
  assert.equal(winRows(10), 17);
});
test('noise levels are full rows', () => {
  const lv = levels.find(l => makeLayout(l).kind === 'noise'), L = makeLayout(lv);
  const rows = Math.max(...[...L.cells.keys()].map(k => rc(k)[0])) + 1;
  for (let r = 0; r < rows; r++) assert.equal([...L.cells.keys()].filter(k => rc(k)[0] === r).length, r % 2 ? L.cols - 1 : L.cols);
});
test('retry keeps the layout, recolours whole groups', () => {
  const lv = levels.find(l => makeLayout(l).kind === 'designed' && l > 10), L = makeLayout(lv);
  const a = colourize(L, lv, 0), b = colourize(L, lv, 1);
  assert.deepEqual([...a.keys()].sort(), [...b.keys()].sort());
  assert.notDeepEqual([...a], [...b]);
  for (const col of [a, b]) {
    const byGroup = new Map();
    for (const [k, g] of L.cells) { if (!byGroup.has(g)) byGroup.set(g, new Set()); byGroup.get(g).add(col.get(k)); }
    for (const [g, s] of byGroup) assert.equal(s.size, 1, `group ${g} has mixed colours`);
  }
  assert.ok(new Set(a.values()).size <= L.nColours);
});

### Task 3: Shot physics

**Files:**
- Modify: `src/core.js` (new section `/* ---------- shots ---------- */`)
- Test: `tests/core.test.mjs`

**Interfaces:**
- Consumes: Task 1 geometry; `winRows` from `src/levels.js`.
- Produces (exported from `src/core.js`):
  - `viewTop(grid, cols) => number`: first visible row, `Math.max(0, low - (winRows(cols) - 5))`, where `low` is the lowest occupied row (0 if empty). The lowest bubble then sits 4 rows above the shooter row.
  - `shooterPos(grid, cols) => {x, y}`: `x = cols`, `y = 1 + (viewTop + winRows(cols) - 1) * RH`.
  - `MIN_ANGLE = 0.12`; `clampAim(ang) => number|null`: `null` for angles `>= 0` (aiming down or flat), otherwise clamped to `[-Math.PI + MIN_ANGLE, -MIN_ANGLE]`.
  - `trace(grid, cols, ang) => {pts: {x, y}[], cell: [r, c] | null}`: fixed steps of `0.25`, side walls at `x = 1` and `x = 2 * cols - 1` reflect (push a point at each bounce), stops at `y <= 1` (ceiling) or when within `HIT = 0.82 * 2` of an occupied centre (check only rows near the current `y`), then snaps.
  - `snap(grid, cols, x, y) => [r, c] | null`: nearest free cell to `(x, y)` among rows `round((y - 1) / RH) - 1` to `+ 2` that is in row 0 or touches an occupied cell; if none, the nearest free neighbour of the nearest occupied cell.

**Interfaces:**
- Consumes: Tasks 1 to 3.
- Produces:
  - In `src/levels.js`: `SHOT_K = {designed: {a, b, c}, noise: {a, b, c}}` (exported, mutable so the sim can try values), `groupCount(layout) => number` (distinct groups), `shotLimit(layout) => number` = `Math.ceil(a * groups + b * bubbles / nColours + c)` with the kind's constants.   - In `src/core.js`:
    - State `S`: `{level, fails, cols, kind, grid: Map<key, colour>, shots, score, cur, next, hist: number[], draws}`.
    - `startState(level, fails) => S`: layout, colours, shots from `shotsFor(shotLimit(layout), fails)`, `score 0`, `draws 0`, then deals `cur` and `next`.
    - `OFFSCREEN_W = 0.3`; `deal(S) => colour|null`: uses `mulberry32(hash(S.level, S.fails, 5, S.draws++))`; colours present on the board, weight 1 if any bubble of that colour is at row `>= viewTop`, else `OFFSCREEN_W`; if the last two in `S.hist` are the same colour, exclude it (unless it is the only colour); if the draw repeats the last colour and more than one colour is in the pool, draw once more; push to `S.hist` (keep 2). `null` on an empty board.
    - `swap(S)`.
    - `fire(S, ang) => {pts, cell, popped: key[], dropped: key[], points} | null`: `null` if `clampAim(ang)` is `null`, `S.shots <= 0` or the board is won. Otherwise places `S.cur`, pops a same-colour group of 3 or more, drops everything not `connected`, adds `10 * popped + 10 * dropped²`, decrements `shots`, moves `next` to `cur` and deals a new `next`, then redraws `cur` or `next` if their colour has left the board.
    - `won(S)` = board empty; `lost(S)` = `!won(S) && S.shots <= 0`.
    - `toSave(S) => object` (grid as `[key, colour][]`, plus `v: 1`), `fromSave(o) => S`, `validSave(o) => boolean` (`v === 1`, integer `level >= 1`, `fails >= 0`, `cols` in `{8, 10, 12}`, array grid of valid keys and colours `0..5`, `cur` and `next` colours or `null`).

import { startState, deal, fire, won, lost, toSave, fromSave, validSave } from '../src/core.js';

const board = (cols, cells) => new Map(cells.map(([r, c, col]) => [key(r, c), col]));
const stateWith = (cols, cells, cur, next = cur) =>
  Object.assign(startState(1, 0), { cols, grid: board(cols, cells), cur, next, hist: [], shots: 10, score: 0 });
// Find an angle whose traced landing cell is [r, c]; tests never guess angles.
const aimAt = (S, r, c) => { for (let a = -Math.PI + 0.12; a <= -0.12; a += 0.001) { const t = trace(S.grid, S.cols, a);
  if (t.cell && t.cell[0] === r && t.cell[1] === c) return a; } throw new Error(`no angle reaches ${r},${c}`); };

test('popping the anchor drops the chain below it', () => {
  const S = stateWith(10, [[0, 0, 1], [0, 1, 1], [1, 0, 2], [2, 0, 2], [3, 0, 2]], 1);
  const m = fire(S, aimAt(S, 0, 2));

  assert.equal(S.grid.size, 0); assert.equal(m.points, 10 * 3 + 10 * 9);
