# Splice Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu button in the HUD (replacing Restart) that opens a full-screen panel with Run, Shop (disabled) and Info tabs: restart, start over, back to the best level, a level stepper, share, source link, license, credits and a language picker, plus a remembered best level.

**Architecture:** The best-level rule and the stepper clamp are pure functions in a new `src/run.js`, tested in `tests/run.test.mjs`. Everything else is DOM in `index.html`, `style.css` and `src/ui.js`: a new `#menu` panel, the existing `#sheet` reused (with a text line) for the restart and start-over questions, and all level starts routed through `begin()`, which applies the best-level rule.

**Tech Stack:** Vanilla JS ES modules, `node:test`. No dependencies, no build step.

**Spec:** `docs/superpowers/specs/2026-10-26-menu-design.md`. Read it before any task. Notes: `CLAUDE.md`.

## Global Constraints

- No frameworks, no dependencies, no build step. Tests: `node --test` from the repo root.
- `src/run.js` is pure: no DOM, no storage.
- Visible text only in `lang/en.json` via `t('key', …)` with literal keys: `tests/lang.test.mjs` requires that `ui.js` uses exactly the keys in `en.json`. Remove keys that become unused (`restart`).
- Copy: sentence case, no em-dashes, typographic apostrophes (’) in visible text.
- Storage: `localStorage['splice-run']` = `{ best, fails }`; `splice-v1` and `validSave` unchanged. Every storage access in `try`/`catch`, as `save()` does.
- New site file `src/run.js` lives under `src/`, which `pages.yml` already copies. Add it to `SHELL` in `sw.js` and bump `CACHE` to `splice-3`.
- Reduced motion: panel and tab switches are instant (no animation at all is fine for everyone).
- Portrait phone width, no horizontal scroll. Compact, terse JS matching `ui.js`.
- Commits: Conventional Commits, imperative, lowercase, no period, about 72 chars; never `Co-Authored-By:` or "Generated with"; stage by path. Ask the owner before each commit.

## Review Focus

1. Typed junk in the stepper (empty, `0`, `-3`, `12.5`, `abc`, a number above best) must never start a level outside 1..best (tests in Task 1).
2. An old player with a save at level 30 and no `splice-run` must get best 30, and a corrupt `splice-run` must not lock the stepper to level 1 (tests in Task 1, manual check in Task 2).
3. A tap on a panel button (Keep playing, Play level, Back to level) must never also aim or fire on the board underneath (manual check in Task 3: `calm()` on close).
4. Opening the menu while a packet flies must not lose the win or loss sheet: the menu button is ignored while `fly` is set (manual check in Task 3).
5. Changing the language with the panel open keeps the Info tab shown and redraws every panel text and the HUD (manual check in Task 4).

### Task 1: Pure run rules

**Files:**
- Create: `src/run.js`
- Test: `tests/run.test.mjs`

**Interfaces:**
- Produces:
  - `runFrom(o, level, fails) -> { best, fails }`: `o` is the parsed `splice-run` value (anything). Returns `o` when it is an object with integer `best >= 1` and integer `fails >= 0`; else `{ best: level, fails }`. Then raises `best` to at least `level` (an old save beyond a stored best).
  - `enter(run, level, fails) -> { run, fails }`: applies the spec's rule. New `best = max(run.best, level)`. If `level > run.best`: begins with `fails` as given and stores it. If `level === run.best`: begins with `max(fails, run.fails)` and stores that. Below best: begins with `fails`, `run` unchanged. Never mutates its input.
  - `clampLevel(text, best, cur) -> int`: `Number(text)` if it is an integer, else `cur`; then clamped into `1..best`.

- [ ] **Step 1: Write the failing tests** in `tests/run.test.mjs` (import from `../src/run.js`):

```js
test('runFrom keeps a valid run, else starts from the save', () => {
  assert.deepEqual(runFrom({ best: 22, fails: 3 }, 14, 0), { best: 22, fails: 3 });
  assert.deepEqual(runFrom(null, 30, 2), { best: 30, fails: 2 });
  for (const bad of [{}, { best: 0, fails: 0 }, { best: '5', fails: 0 }, { best: 5, fails: -1 }, { best: 2.5, fails: 0 }, 'x'])
    assert.deepEqual(runFrom(bad, 7, 1), { best: 7, fails: 1 });
  assert.equal(runFrom({ best: 5, fails: 0 }, 9, 0).best, 9);
});
test('enter: a new level becomes best with its fails', () => {
  assert.deepEqual(enter({ best: 22, fails: 4 }, 23, 0), { run: { best: 23, fails: 0 }, fails: 0 });
  assert.deepEqual(enter({ best: 22, fails: 4 }, 50, 0), { run: { best: 50, fails: 0 }, fails: 0 });
});
test('enter: the best level keeps its earned fails on every path', () => {
  assert.deepEqual(enter({ best: 22, fails: 4 }, 22, 0), { run: { best: 22, fails: 4 }, fails: 4 });   // back, pick, next from 21
  assert.deepEqual(enter({ best: 22, fails: 4 }, 22, 5), { run: { best: 22, fails: 5 }, fails: 5 });   // try again
});
test('enter: lower levels leave the run alone', () => {
  const run = { best: 22, fails: 4 };
  assert.deepEqual(enter(run, 14, 0), { run: { best: 22, fails: 4 }, fails: 0 });
  assert.deepEqual(enter(run, 1, 2), { run: { best: 22, fails: 4 }, fails: 2 });
  assert.deepEqual(run, { best: 22, fails: 4 });   // not mutated
});
test('clampLevel keeps typed numbers in 1..best', () => {
  assert.equal(clampLevel('14', 22, 9), 14);
  assert.equal(clampLevel('999', 22, 9), 22);
  assert.equal(clampLevel('0', 22, 9), 1);
  assert.equal(clampLevel('-3', 22, 9), 1);
  for (const junk of ['', 'abc', '12.5', ' ']) assert.equal(clampLevel(junk, 22, 9), 9);
  assert.equal(clampLevel('', 22, 40), 22);   // cur above best (a ?level visit) still clamps
});
```
